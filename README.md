# Number Guessing Game

![Screenshot of Number Guessing Game](./Screenshot%202024-09-04%20180741.png)

A simple, responsive number guessing game built with HTML, CSS, and JavaScript.

**Description**

This project is a lightweight browser game where the player attempts to guess a secret number within a limited number of attempts. The UI gives feedback (too high / too low) and displays the player[...] 


## Features

- Clean and responsive UI
- Guess validation and helpful feedback
- Score tracking and high score display
- Easy to run in any modern browser (no build tools required)

## How to play

1. Open `index.html` in your browser.
2. The game generates a secret number between 1 and 20.
3. Enter your guess in the input box and click "Check".
4. The game will tell you if your guess is too high, too low, or correct.
5. Each wrong guess reduces your score. Try to get the highest score possible!

## Run locally

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Number-Guessing-Game-2.git

2. Open `index.html` in your favorite browser.

No additional setup or dependencies are required.
